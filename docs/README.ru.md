# CodeSaver

CodeSaver — кроссплатформенная консольная утилита для создания ZIP-снимков проектов с исходным кодом. Она использует стандартную библиотеку Python, выполняет автосохранение в фоне и автоматически определяет язык интерфейса системы.

## Быстрый старт

```bash
python -m venv .venv
python -m pip install -e .
codesaver
```

Однократный бэкап без меню:

```bash
codesaver --project-dir ./my-project --backup-dir ./backups --backup-now
```

Восстановление архива:

```bash
codesaver --project-dir ./my-project --restore ./backups/my-project_2026-01-20_14-30-00.zip --overwrite
```

Интервал автосохранения по умолчанию — 600 секунд. Используйте `--no-autosave`, чтобы отключить его, `--interval 300`, чтобы изменить интервал, и `--language de`, чтобы принудительно выбрать язык. `.git`, `__pycache__`, виртуальные окружения и кэши инструментов исключаются автоматически.
