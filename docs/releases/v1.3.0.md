# CodeSaver CLI v1.3.0

## Highlights

- Added `--disk-check` for backup-destination capacity checks.
- Added `--verify-latest` for quick CI validation of the newest archive.
- Added `--file-report` with extension-level file and byte totals.
- Added `--archive-members` for JSON archive-content inspection.
- Added `--prune-preview` to review cleanup candidates before deletion.
- Added `--git-diff-summary` for a compact working-tree change summary.

## Validation

- 46 tests passed locally.
- Black and Flake8 passed.
