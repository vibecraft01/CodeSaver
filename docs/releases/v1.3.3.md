# CodeSaver CLI v1.3.3

## Highlights

- Added `--duplicates` for SHA-256 duplicate detection.
- Added `--recent-files` and `--root-directories` for project activity analysis.
- Added `--git-log` for compact commit history in reports.
- Added `--verify-all` for complete archive validation.
- Added `--diff-latest` to compare against the newest backup.
- Added `--unreadable-files` for pre-backup permission checks.
