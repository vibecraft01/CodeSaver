# CodeSaver CLI v1.1.9

Released on 2026-08-23.

## Highlights

- Added `--report FILE` for a portable JSON backup summary.
- Reports include the project, archive, file count, source bytes, duration, verification, manifest, and cleanup count.
- Designed for CI artifacts, scheduled jobs, and audit trails.

## Validation

- Full test suite: 37 tests passed.
- Black and Flake8 passed.

## Example

```bash
python -m codesaver --project-dir . --backup-now --verify --report reports/backup.json
```
