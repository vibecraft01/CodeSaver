# CodeSaver Desktop v1.7.3

Improved project comparison workflow:

- Review added, modified, and missing files in a dedicated results table.
- See category counts together in a comparison summary.
- Filter the table by change status.
- Search paths immediately as you type.
- Export visible results to CSV, copy a selected path, or open its file location.

Desktop source is included in the tagged repository source archive. Standalone builds are provided for Windows, macOS, and Linux.
