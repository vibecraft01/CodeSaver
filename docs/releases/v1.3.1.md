# CodeSaver CLI v1.3.1

## Highlights

- Added `--largest-files` for finding oversized project files.
- Added `--changed-files` for Git working-tree status in scripts.
- Added `--archive-checksums` for per-member SHA-256 audit output.
- Added `--config-show` to inspect effective backup settings.
- Added `--directory-report` for folder-level file and byte totals.
- Added `--project-check` and `--estimate-size` for pre-backup validation and planning.
