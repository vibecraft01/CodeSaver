# CodeSaver CLI v1.1.5

This local CLI update adds safer previews, archive verification, and command-line control over directory exclusions.

## What's new

- `--dry-run` lists included files and total size without writing a ZIP archive.
- `--verify` validates ZIP structure and CRCs after backup creation or before restore.
- Repeatable `--exclude-dir DIR` excludes generated or tool-specific directories for one run.
- Clear verification and dry-run summaries improve scripted workflows.

## Local validation

- Existing tests and new CLI/core tests pass locally.
- Black and Flake8 checks pass locally.
