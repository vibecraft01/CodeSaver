# CodeSaver CLI v1.8.4

Four new backup-management workflows:

- `--backup-retention DAYS` previews archives older than the selected age; use `--apply-retention` to remove them.
- `--restore-preflight ARCHIVE` checks CRC integrity, unsafe paths, existing-file conflicts, and free disk space before restore.
- `--restore-drill ARCHIVE` extracts and hashes every file in a temporary directory without changing the project.
- `--backup-manifest-json FILE` writes a JSON catalog with archive timestamps, sizes, SHA-256 hashes, file counts, and CRC status.

All CLI and Desktop source files are available in the tagged repository source archive. The release also provides standalone CLI binaries for Windows, macOS, and Linux.
