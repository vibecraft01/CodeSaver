# CodeSaver Desktop v1.6.0

## New functions

- Verify the selected archive's ZIP CRC.
- Filter archive members with case-insensitive glob patterns.
- Safely extract one chosen member to a selected folder without overwriting existing files.
- Export a detailed SHA-256 comparison of two archives as JSON.
- Inspect compression savings for each file in the selected archive.
