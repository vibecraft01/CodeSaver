# CodeSaver CLI v1.3.4 (local)

## Highlights

- Added `--project-summary` with file, size, and extension statistics.
- Added `--archive-search` for quickly finding backup archives by name.
- Added `--git-status-json` for CI and developer tooling integrations.
- Added `--export-inventory FILE` to create a CSV inventory of project files.
- Added `--restore-preview ARCHIVE` to inspect archive contents before restoring.

## Validation

- Full test suite passed locally.
- Black and Flake8 passed.
- CLI smoke tests passed locally.
