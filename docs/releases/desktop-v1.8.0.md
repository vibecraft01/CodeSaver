# CodeSaver Desktop v1.8.0

- Add a warm autumn theme to the Desktop appearance settings.
- Add a separate setting to disable CodeSaver's custom styling and use the platform's default widget appearance.
- Add a backup-evolution window that lists file additions, modifications, and removals between consecutive snapshots.
- Search the evolution table by path or archive name and export the visible filtered results to CSV.

The Desktop source is included in the tagged repository source archive. Windows, macOS, and Linux packages are attached to this release.
