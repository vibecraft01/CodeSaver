# CodeSaver CLI v1.9.0

Inspect how project files changed between consecutive backup archives:

- Run `codesaver --project-dir . --backup-dir .\backups --backup-evolution` for added, modified, and removed file counts per snapshot transition.
- Narrow results with `--evolution-path src/`.
- Export each changed path and its before/after byte size with `--evolution-csv .\evolution.csv`.
- Add `--evolution-fail-on-change` to return exit status 1 when any file changed, for use in scripts and CI.
- Use `--json` to emit the complete machine-readable report.

File contents are hashed, so modifications that retain the same size are still detected. The CLI source is included in the tagged repository source archive; Windows, macOS, and Linux binaries are attached to this release.
