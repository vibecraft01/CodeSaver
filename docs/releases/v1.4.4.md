# CodeSaver CLI v1.4.4

## Highlights

- `--backup-names` lists saved backup archives.
- `--storage-paths` reports project and backup locations.
- `--environment-json` exports runtime diagnostics.
- `--project-tree-csv FILE` exports a project inventory.
- `--archive-manifest-csv ARCHIVE` exports archive members to a matching CSV file.
