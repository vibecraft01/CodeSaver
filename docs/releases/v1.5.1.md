# CodeSaver CLI v1.5.1

## New functions

- `--backup-size-by-day-json` summarizes backup storage by date.
- `--project-hashes-json FILE` exports SHA-256 hashes for project files.
- `--archive-empty-members ARCHIVE` lists zero-byte archive members.
- `--project-depth-summary` summarizes files by directory depth.
- `--backup-name-pattern TEXT` finds backup archives by name.

Released 8 September 2026 after green validation.
