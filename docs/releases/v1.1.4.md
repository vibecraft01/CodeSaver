# CodeSaver CLI v1.1.4

CodeSaver CLI v1.1.4 adds safer automation, clearer progress reporting, and more flexible project selection.

## What's new

- ETA in backup progress output, based on the current file-processing speed.
- Automatic Russian/English locale detection without requiring `--language`.
- Glob exclusion templates in `.codesaver.json`, including patterns such as `*.tmp`, `*.log`, and `temp_*`.
- Optional symbolic-link traversal with `--follow-symlinks`.
- Interactive recent-project selection when the CLI starts without arguments.
- Read errors include the affected path; the backup continues with the remaining files.
- Age-based backup cleanup through `--keep-days`.

## Validation

- Full test suite: 28 tests passed.
- Black formatting check passed.
- Flake8 lint check passed.
- Existing compression, size filtering, retention, `.gitignore`, logging, restore, and localized CLI behavior preserved.

The CLI release does not include the optional Desktop application. Desktop remains available separately as `v1.0.1`.
