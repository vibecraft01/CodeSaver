# CodeSaver CLI v1.5.2

## New functions

- `--backup-total-growth` compares backup storage with project size.
- `--project-empty-files` lists zero-byte project files.
- `--archive-largest-member ARCHIVE` finds the largest archive member.
- `--git-commit-count-json` exports the repository commit count.
- `--project-symlink-count` counts symbolic links in the project.

## Validation

- Black, Flake8, and Python compilation passed locally.
