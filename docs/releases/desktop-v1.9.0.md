# CodeSaver Desktop v1.9.0

## Highlights

- Save current backup settings as named profiles from Project Tools.
- Apply profiles to quickly switch destination, exclusions, compression, size limit, and retention.
- Remove obsolete profiles with a confirmation prompt.
- Profiles are shared with the CLI through the user's local profile store.

## Validation

- Profile input and stored values are validated by the shared profile module.
- Applying a profile persists settings and rebuilds the active backup manager for the selected project.
