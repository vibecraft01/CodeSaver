# CodeSaver Desktop v1.6.10

## New archive inspection features

- Find nested ZIP archives by inspecting member signatures.
- List members carrying ZIP64 metadata.
- List files that store CRC and size data in data descriptors.
- Detect bytes appended after the ZIP end record.
- Inspect optional digital-signature records after the central directory.
