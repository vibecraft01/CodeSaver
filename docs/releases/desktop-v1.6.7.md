# CodeSaver Desktop v1.6.7

## New functions

- Detect absolute and drive-qualified archive paths.
- Find Unicode compatibility-normalized path collisions.
- Detect repeated ZIP extra-field records.
- Flag risky Unix permission bits such as setuid and world-writable.
- Identify archived devices, FIFOs, and sockets.

Released on 3 October 2026 after green validation.
