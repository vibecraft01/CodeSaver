# CodeSaver Desktop v1.6.9

- Find legacy-encoded names without the UTF-8 filename flag.
- Inspect WinZip AES encryption metadata.
- Summarize compressed and uncompressed storage by archive folder.
- Detect self-extracting ZIP preambles and report their signature.
