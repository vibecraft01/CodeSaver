# CodeSaver CLI v1.7.2

## New functions

- Verify every member's ZIP CRC with `--archive-verify-crc`.
- Search archive members using a case-insensitive glob pattern.
- Safely extract one selected member to a separate directory; traversal and overwrites are rejected.
- Compare two ZIP snapshots by SHA-256 and report added, removed, and changed members.
- Report per-file compressed size and storage savings.

Released on 26 September 2026 after green validation.
