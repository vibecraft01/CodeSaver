# CodeSaver CLI v1.2.9

## Highlights

- Added `--list-backups` for machine-readable backup inventory.
- Added `--latest` to resolve the newest archive in scripts and CI jobs.
- Added `--storage-report` with a file-extension summary of the project.
- Added `--check-project` for a pre-backup file scan.
- Added `--plan` to preview the backup target and file count without writing an archive.

## Validation

- 46 tests passed locally.
- Black and Flake8 passed.
