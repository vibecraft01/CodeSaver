# CodeSaver CLI v1.7.4

## New functions

- Detect duplicate file paths stored multiple times in a ZIP.
- Find case-insensitive member-name collisions that can behave differently across operating systems.
- List files marked as encrypted in ZIP metadata.
- Summarize compression methods and raw/stored byte totals.
- Identify members whose uncompressed-to-compressed ratio exceeds a chosen threshold.

Released on 27 September 2026 after green validation.
