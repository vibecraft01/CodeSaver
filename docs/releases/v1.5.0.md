# CodeSaver CLI v1.5.0

## New functions

- `--backup-dates-json` exports backup timestamps and sizes.
- `--project-size-by-dir-json FILE` exports directory size totals.
- `--archive-extension-count ARCHIVE` counts archive members by extension.
- `--git-branches-json` exports local Git branches as JSON.
- `--project-top-files N` lists the largest project files.
