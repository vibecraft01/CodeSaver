# CodeSaver Desktop v1.0.6

Released on 2026-08-23.

## Highlights

- Added a backup storage summary showing archive count and total disk usage.
- Added archive context actions to copy an archive path or open its containing folder.
- Added keyboard shortcuts: `Ctrl+B` for backup, `Ctrl+R` for restore, and `F5` to refresh.
