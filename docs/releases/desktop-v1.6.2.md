# CodeSaver Desktop v1.6.2

## New functions

- Detect duplicate file paths stored multiple times in the selected archive.
- Find case-insensitive path collisions that can break cross-platform extraction.
- List encrypted archive members.
- Summarize compression methods and byte totals.
- Flag unusually high expansion ratios using a user-selected threshold.
