# CodeSaver CLI v1.1.3

## What's new

- Added repeatable `--exclude-ext` filtering, for example `--exclude-ext .tmp --exclude-ext .log`.
- Added `exclude_ext` support in `.codesaver.json`.
- Added localized help and validation errors for extension filters.
- Preserved all v1.1.2 compression, size filtering, progress, retention, and `.gitignore` features.

## Validation

- Existing and new CLI tests pass.
- Black and Flake8 pass.
- Windows CLI smoke testing completed successfully.
