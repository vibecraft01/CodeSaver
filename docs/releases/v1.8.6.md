# CodeSaver CLI v1.8.6

Project-diff workflow improvements:

- Filter `--diff ARCHIVE` results to one category with `--diff-status added|modified|missing`.
- Limit results to paths containing text with `--diff-path TEXT`.
- Export the filtered comparison as JSON with `--diff-report FILE`.
- Export the filtered comparison as CSV with `--diff-csv FILE`.
- Use `--fail-on-diff` to return exit code 1 when the selected comparison contains differences, useful in CI.

Examples:

```powershell
codesaver --project-dir . --diff backups\project.zip --diff-status modified --diff-path src\
codesaver --project-dir . --diff backups\project.zip --diff-report diff.json --diff-csv diff.csv --json
codesaver --project-dir . --diff backups\project.zip --fail-on-diff
```

The CLI source is included in the tagged repository source archive. Standalone builds are provided for Windows, macOS, and Linux.
