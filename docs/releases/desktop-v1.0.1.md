# CodeSaver Desktop v1.0.1

This release improves the CodeSaver Desktop experience while keeping the existing PyQt5 backup workflow compatible.

## Highlights

- Automatically follows the Windows system light/dark theme through the new System theme option.
- Shows project file count and total size immediately after selecting a folder.
- Uses smooth animated progress updates with percentage and processed byte totals.
- Adds an Open Backups Folder action to the main window.
- Restores the last selected project automatically on startup.
- Includes refreshed Windows packaging and a Linux package version aligned to Desktop 1.0.1.

## Downloads

- `CodeSaverDesktop-windows-x64.exe` for Windows.
- `CodeSaverDesktop-macos.zip` for macOS.
- `CodeSaverDesktop-linux-amd64.deb` for Debian-based Linux distributions.

Python 3.10+ and PyQt5 are required when running from source. The Desktop application does not require API keys.
