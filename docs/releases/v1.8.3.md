# CodeSaver CLI v1.8.3

## New backup-history workflows

- Compare the two newest backup ZIPs with `--backup-latest-diff`.
- Rank the largest files in the newest backup with `--backup-largest-members N`.
- Find byte-identical backup archives with `--backup-identical-archives`.
- Export an archive-by-archive size history with cumulative totals using `--backup-history-csv FILE`.
- Check total backup storage against a byte budget with `--backup-budget BYTES`.

All five commands support `--json` where a structured report is useful. CSV output creates its parent directory when needed.
