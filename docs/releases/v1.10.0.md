# CodeSaver CLI v1.10.0

## Highlights

- Save effective backup settings as a reusable named profile with `--profile-save NAME`.
- List profiles with `--profile-list`, apply one with `--profile NAME`, or remove one with `--profile-delete NAME`.
- Profiles cover destination, exclusions, compression, size limits, retention, symlink handling, and `.gitignore` behavior.
- Profiles are shared with CodeSaver Desktop and stored in the user's local `~/.codesaver-profiles.json` file.

## Validation

- Profile names and setting types are validated before changes are written.
- Profile updates use atomic replacement to avoid partially written configuration.
