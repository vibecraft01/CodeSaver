# CodeSaver v1.1.2

This release adds practical controls for managing larger and more frequent project backups while keeping the existing cross-platform CLI architecture.

## What's new

- `--compress` enables maximum ZIP DEFLATE compression.
- `--max-size` excludes files above a configurable size, such as `100M`, `100MiB`, or a byte count.
- Progress output now reports both processed files and processed data size in real time.
- `--keep-last N` automatically removes older backups for the current project.
- Root `.gitignore` rules are applied automatically, with `--no-gitignore` available as an override.
- All new CLI messages are localized across the supported interface languages.
- Configuration supports `compress`, `max_size`, `keep_last`, and `use_gitignore`.
