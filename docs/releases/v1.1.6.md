# CodeSaver CLI v1.1.6

## Highlights

- `--manifest` embeds a `.codesaver-manifest.json` file containing SHA-256 hashes and sizes for every archived file.
- `--verify` now validates both ZIP CRC integrity and the optional SHA-256 manifest.
- Added localized CLI help and status output for the new integrity workflow.

## Validation

- Full test suite passes locally.
- Black and Flake8 checks pass.
- Windows, macOS, and Linux release artifacts are built by GitHub Actions from the tagged release.
