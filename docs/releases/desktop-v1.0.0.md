# CodeSaver Desktop v1.0.0

The first graphical CodeSaver application, built with Python and PyQt5.

## What's included

- Project folder selection and project statistics.
- Backup creation with real-time file and byte progress.
- Archive table with date and size information.
- Double-click restore with overwrite confirmation.
- Settings for exclusions, extensions, autosave, retention, language, theme, compression, and backup location.
- Background autosave, system-tray minimization, and desktop notifications.
- Reuse of the existing CodeSaver backup and restore core.

## Requirements

Python 3.10+ and PyQt5. No API keys or external services are required.
