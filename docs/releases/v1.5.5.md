# CodeSaver CLI v1.5.5

## New functions

- `--backup-latest-age` shows the age of the newest backup.
- `--project-name-summary` summarizes project file names.
- `--archive-member-depth ARCHIVE` summarizes archive paths by depth.
- `--git-remote-count-json` exports configured Git remotes as JSON.
- `--project-largest-files-json FILE` exports the ten largest files.

Released on 10 September 2026 after green validation.
