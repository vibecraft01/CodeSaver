# CodeSaver CLI v1.2.0 (local)

Planned local release date: 2026-08-23

## Highlights

- Added `--diff ARCHIVE` to compare the current project with a ZIP snapshot.
- Reports added, modified, and missing files before a restore.
- Supports `--json` for CI pipelines and automation.
- Reuses ZIP integrity and SHA-256 manifest validation before comparing files.

## Examples

```bash
codesaver --project-dir ./my-project \
  --diff ./backups/my-project_2026-08-21_23-21-31.zip

codesaver --project-dir ./my-project \
  --diff ./backups/latest.zip --json
```

This release is prepared and tested locally only. It has not been uploaded to GitHub.
