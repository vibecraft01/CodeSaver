# CodeSaver Desktop v1.7.4

Organize the archive list with local labels and notes:

- Edit an archive's label and note from its context menu.
- Search by archive filename, label, or note.
- Filter the list to one label.
- Export the full annotated archive catalog as CSV or JSON.
- Preserve annotations when renaming an archive and remove them when deleting it.

Annotations are stored in `.codesaver-metadata.json` inside the backup directory. Desktop source is included in the tagged repository source archive. Standalone builds are provided for Windows, macOS, and Linux.
