# CodeSaver Desktop v1.7.0

## Redesigned interface and new tools

- Reworked the main window with a compact responsive action bar, clearer project card, and updated archive-list styling.
- Moved less-frequent actions into the workspace menu so the primary controls remain visible at narrower window sizes.
- Filter backups by all dates or the last 7, 30, or 90 days.
- Preview a selected archive's creation time, compressed size, and file count.
- Switch between compact and comfortable archive-row density.

Existing project and archive tools remain available from the workspace menu and archive context menu.
