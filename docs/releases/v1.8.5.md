# CodeSaver CLI v1.8.5

Portable recovery additions:

- Restore a complete archive into another directory without changing the original project: `codesaver --restore project.zip --restore-to recovered-project`.
- Restore only selected archive members elsewhere: `codesaver --restore-files project.zip src/app.py --restore-files-to recovered-project`.
- Archive traversal paths, duplicate destinations, and existing-file conflicts are checked before extraction starts. Existing files are not overwritten unless `--overwrite` is explicitly supplied.

CLI source is included in the tagged repository source archive. Standalone builds are provided for Windows, macOS, and Linux.
