# CodeSaver Desktop desktop-v1.7.2

Portable recovery additions:

- Use an archive's context menu to restore the full snapshot into a folder you choose, without touching the currently open project.
- Restore selected archive files into a chosen folder.
- Destination conflicts and unsafe archive paths are checked before extraction; existing files in the selected folder are preserved.

Desktop source is included in the tagged repository source archive. Standalone builds are provided for Windows, macOS, and Linux.
