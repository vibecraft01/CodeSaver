# CodeSaver CLI v1.7.5

## New functions

- Audit Windows-incompatible names, reserved devices, invalid characters, and trailing dots/spaces.
- Find paths colliding after Unicode NFC normalization and case folding.
- Report file counts by archive path depth and the deepest member paths.
- Detect absolute or parent-traversing symbolic-link targets.
- Find archive entries where a regular file conflicts with a nested child path.

Released on 28 September 2026 after green validation.
