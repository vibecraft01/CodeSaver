# CodeSaver Desktop v1.1.0

## Highlights

- Added JSON backup inventory export with archive names, paths, sizes, and timestamps.
- Added an `Export JSON report` action for audits and support diagnostics.
- Added instant backup search by filename/date in the archive list.
- Added automatic archive-list refresh and an `F5` refresh shortcut.

## Validation

- 43 tests passed locally.
- Black and Flake8 passed.
- Windows Desktop executable smoke test passed locally.
- PyQt5 Desktop packaging completed with PyInstaller.
