# CodeSaver CLI v1.8.7

Organize and search local backup archives with persistent annotations:

- Add or update a label with `--backup-label ARCHIVE LABEL`.
- Add or update a note with `--backup-note ARCHIVE NOTE`.
- Search archive names, labels, and notes using `--backup-metadata-search TEXT`.
- Export the archive catalog, including labels and notes, to JSON or CSV with `--backup-catalog-export FILE`.

The annotation index is stored as `.codesaver-metadata.json` inside the configured backup directory. Archive paths are restricted to existing ZIP files directly in that directory.

```powershell
codesaver --project-dir . --backup-dir .\backups --backup-label project_20261013.zip nightly
codesaver --project-dir . --backup-dir .\backups --backup-note project_20261013.zip "Before migration"
codesaver --project-dir . --backup-dir .\backups --backup-metadata-search migration --json
codesaver --project-dir . --backup-dir .\backups --backup-catalog-export .\backup-catalog.csv
```

The CLI source is included in the tagged repository source archive. Standalone builds are provided for Windows, macOS, and Linux.
